# Security Policy

## Supported Versions

Projemizin halihazırda bakımının yapıldığı sürümler için güvenlik güncellemeleri sunuyoruz.



Güvenlik düzeltmeleri öncelikle en son kararlı sürüme uygulanır. Gerekli olduğu durumlarda, önceki kararlı sürüm için de kritik güvenlik düzeltmeleri sağlanabilir.

Daha eski sürümler, kullanımdan kaldırılmış sürümler ve resmi olmayan sürümler için güvenlik güncellemelerinin sağlanacağı garanti edilmez. En güncel güvenlik yamalarını alabilmek için tüm kullanıcıların kurulumlarını en son kararlı sürüme güncel tutmalarını öneririz.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

If you believe you have found a security vulnerability in our application or systems, please report it to us responsibly.

You can sen security vulnerability reports to:

**Email :** hkntekelioglu@gmail.com

Please include as much detail as possible, such as:

-A short descriptionof the vulneratbility 

-The affected page, feature, API, or system component

-Steps to reproduce the issue

-Any screenshots, videos, logs, or technical details

-Your name and contact email,if you would like us to follow up

After we receive your report, we will review it as soon as possible. We usually acknowledge valid reports within **3 business day**. During the review process, we may contact you for addiotional information.

If the vulnerability is confirmed, we will assess its impact,prioritize the fix, and keep you updated on the resolution. If the report is not accepted as a security vulnerability, we will explain the reasen whenever possible.

Please do not publicy disclose the vulnerability before giving us a reasonable amount of time to investigate and fix it. We also ask that you avoid testing methods that could harm user data, disrupt service availability, or compromise system integrity.
